Period summaries and ledger rows describe the same blocks; count them once.
Estimates draw on the project collaboration and delivered milestones; they are
rounded allocations rather than tracked hours. Earlier work in reference projects
is not counted again here. Future work adds a new period, and revised estimates
record the adjustment. Gifts received are tracked separately, if recorded.
